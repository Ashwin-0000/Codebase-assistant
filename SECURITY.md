# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | ✅ Yes     |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, email **security@your-org.example** with:

1. A description of the vulnerability and its potential impact.
2. Steps to reproduce (or a proof-of-concept).
3. Any suggested mitigations.

We aim to acknowledge reports within **48 hours** and to release a patch within
**14 days** for high-severity issues.

Once the vulnerability is fixed we will publish a [GitHub Security Advisory](https://docs.github.com/en/code-security/security-advisories/working-with-repository-security-advisories/about-repository-security-advisories)
and credit you (unless you prefer to remain anonymous).
